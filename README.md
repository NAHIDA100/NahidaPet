# 🌿 小草神桌宠 - NahidaPet

原神 Q 版纳西妲（小草神）桌面宠物，悬浮在手机桌面上陪你~

## ✨ 功能

- **桌面悬浮宠物**：Q 版纳西妲形象，可拖拽移动
- **短按互动**：弹跳动画 + 随机对话气泡
- **长按聊天**：长按 2 秒弹出输入框，与纳西妲自由对话
- **AI 对话**：支持 DeepSeek / 小米 MiMo 两大 AI 平台
- **长期聊天**：完整聊天界面，支持历史记录、自定义昵称和头像
- **纳西妲人设**：锁定角色身份，防注入
- **仅桌面显示**：打开其他 App 自动隐藏，回到桌面自动出现
- **多品牌适配**：支持华为/荣耀/小米/OPPO/vivo/三星/一加/Pixel 等桌面启动器
- **防杀后台**：电池优化白名单 + Shizuku 权限双方案
- **开机自启**：重启后自动恢复桌宠
- **屏幕自适应**：手机/平板自动适配

## 📱 系统要求

- Android 5.0 (API 21) ~ Android 17
- 需要悬浮窗权限
- AI 对话需要 API Key（DeepSeek 或小米 MiMo）

## 🔧 构建

1. 用 Android Studio 打开项目
2. Sync Gradle
3. Run on device（需要真机，模拟器不支持悬浮窗）

## 📦 下载

直接下载 `NahidaPet-v2.5-release.apk` 安装即可。
